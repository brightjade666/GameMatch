# GameMatch 接口文档

## 约定

- 基础地址：`http://localhost:8081`
- 统一响应：`{"code": 200, "msg": "操作成功", "data": ...}`
- 除白名单接口外，请求需携带 `Authorization: Bearer <accessToken>`。
- 管理接口除 JWT 有效外，还要求登录用户具有管理员角色。

## 认证授权

| 方法 | 路径 | 作用 | 主要参数 |
| --- | --- | --- | --- |
| POST | `/register` | 注册用户 | JSON：`username`、`password` |
| POST | `/login` | 登录并签发双 Token | JSON：`username`、`password` |
| POST | `/refresh-token` | 使用 RefreshToken 换取新双 Token | Header：`X-Refresh-Token` |
| POST | `/logout` | 退出并使 Redis 登录态失效 | Header：`Authorization` |

登录响应包含 `access_token`、`refresh_token` 以及有效期。RefreshToken 每次使用后轮换，旧 RefreshToken 随即失效。

## 用户与匹配

| 方法 | 路径 | 作用 | 主要参数 |
| --- | --- | --- | --- |
| GET | `/user/info` | 获取个人资料 | `userId` |
| POST | `/user/update` | 更新个人资料 | JSON：用户资料 |
| GET | `/user/publicInfo` | 获取公开资料 | `userId` |
| GET | `/user/match` | 基础用户匹配 | `gameId` |
| GET | `/user/matchAdvanced` | 按游戏、时间、需求和性格综合匹配 | `gameName`、`playtimeStart`、`playtimeEnd` 等 |

## 队伍、推荐与排行

| 方法 | 路径 | 作用 | 主要参数 |
| --- | --- | --- | --- |
| GET | `/team/list` | 查询队伍列表 | 可选 `userId` |
| GET | `/team/detail/{teamId}` | 查询队伍详情并累计浏览热度 | 路径参数 `teamId` |
| GET | `/team/hot/top` | 从 Redis ZSet 查询热门队伍 Top N | 可选 `limit` |
| GET | `/team/hot/rank/{teamId}` | 查询指定队伍热度排名 | 路径参数 `teamId` |
| GET | `/team/match` | 按当前用户游戏偏好推荐热门队伍 | 可选 `limit` |
| POST | `/team/publish` | 发布队伍 | JSON：`TeamRecruit` |
| POST | `/team/comment` | 发表评论 | `teamId`、`userId`、`content` |
| POST | `/team/apply` | 申请加入队伍 | JSON：`teamId`、`userId` |
| GET | `/team/my/applies` | 查询队长收到的申请 | `leaderId` |
| POST | `/team/agree` | 同意入队申请 | `id` |
| POST | `/team/reject` | 拒绝入队申请 | `id` |
| GET | `/team/my/joined` | 查询已加入队伍 | `userId` |
| GET | `/team/created` | 查询创建的队伍 | `leaderId` |
| POST | `/team/leave` | 退出队伍 | `teamId`、`userId` |
| POST | `/team/dissolve` | 解散队伍 | `teamId`、`leaderId` |
| POST | `/team/remove` | 队长移除成员 | `teamId`、`leaderId`、`userId` |
